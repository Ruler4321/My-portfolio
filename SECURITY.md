# 🛡️ Политика безопасности (Security Policy)

Привет! Я серьезно отношусь к безопасности своего сайта на GitHub Pages. 

## 🚀 Поддерживаемые версии
Безопасность тестируется и поддерживается только для главной ветки проекта:

| Версия | Поддержка |
| :--- | :---: |
| Главная (main) | ❤️ Поддерживается |

## 🐛 Как сообщить об уязвимости
Если ты нашёл критическую ошибку в коде или уязвимость безопасности:
1. **Не пиши об этом открыто в Issues**, чтобы никто не успел этим воспользоваться.
2. Пожалуйста, создай личное обращение или свяжись со мной через вкладку **Discussions** (если они включены) либо оставь приватный тикет.

Спасибо, что помогаешь защищать код проекта **Ruler4321** под лицензией **Apache 2.0**!
