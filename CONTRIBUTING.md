## 🚀 Как ты можешь помочь?

Ты можешь внести свой вклад в развитие проекта следующими способами:
* 🐛 **Найти баги:** Если на сайте что-то сломалось, криво отображается на телефоне или ссылка ведет не туда — дай мне знать!
* 🎨 **Улучшить стили:** Предложить красивую цветовую схему, крутые анимации или улучшить разметку **Flexbox**.
* ✍️ **Исправить опечатки:** Если в текстах или документации Markdown закралась ошибка.

---

## 🛠️ Порядок внесения изменений (Workflow)

Чтобы предложить изменения, следуй этим простым шагам:

1. **Сделай Fork** репозитория (скопируй проект к себе в аккаунт).
2. **Создай новую ветку** для своих изменений:
   ```bash
   git checkout -b feature/cool-feature
   ```
3. **Внеси изменения** в код (пиши аккуратно, соблюдай семантику HTML5 и чистоту Markdown).
4. **Сделай Commit** с понятным описанием того, что ты сделал:
   ```bash
   git commit -m "Добавил крутые стили для кнопок меню"
   ```
5. **Отправь Pull Request (PR)** в мой репозиторий.

## 📜 Правила кодинга (Code Style)
* Никакого лишнего мусора в коде.
* Только чистый HTML5, CSS3 и Markdown.
* Весь код защищен лицензией **Apache 2.0**, поэтому твои изменения тоже станут частью открытого ПО!
